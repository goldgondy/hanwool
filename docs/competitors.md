# 경쟁 서비스 비교 (2026-10-02)

## 코택스 (kointax.kr)
- **대상**: 국내·해외 거래소 개인 투자자. 세무 대리·신고 대행은 하지 않는 "계산·자료 생성 도구".
- **지원**: 업비트·빗썸·바이낸스·바이비트 4곳. 지갑·블록체인 없음. **현물만** (선물 제외).
- **연결 방식**: 업비트는 거래 내역 **화면 복사·붙여넣기** (업비트가 파일 내보내기를 주지 않음), 빗썸·바이낸스·바이비트는 파일 업로드(180일 단위),
  API 자동 연동은 월 구독 전용. 바이낸스 API는 "전량 매도한 코인은 심볼을 직접 입력"하게 함.
- **계산**: 이동평균법 기본 + 선입선출·거래소별 혼합 선택, 의제취득가(실제 vs 2026년 말 시가 중 큰 값), 손익통산, 250만원 공제, 22%.
  해외 거래소 원화 자동 환산. 2027-01-01 보유분 직접 입력.
- **결과물**: 신고용 엑셀 3시트 (신고요약·자산별손익·거래명세), 무제한 다운로드. 홈택스 입력 순서 안내, "표를 클릭해 Ctrl+C/V".
- **부가**: 절세 관리(보유 평가손익, 연내 손실 정리 시 절세액 시뮬레이션), 가입 없는 간이 계산기, 구글·네이버·이메일 로그인.
- **요금**: 3개월 9,900원 / 월 12,900원 / 1년 129,000원. 7일 환불(계산·다운로드 전).
- **보안**: API 키 암호화 서버 저장, 구독 종료 시 삭제.

## 코인허브 (coinhub.kr)
- 개인이 운영하는 무료 계산기 + 시세·김프·테마 정보 사이트.
- **계산은 브라우저에서만** (서버 전송·저장 없음) — 우리와 같은 방식.
- 입력 3가지: 파일 업로드, 직접 입력, **간단 입력(코인마다 금액 두 개)**.
- **매도 플랜**: 필요한 금액을 넣으면 세금이 가장 적은 매도 순서(손실 코인 먼저, "받는 돈 1원당 이익"이 작은 순)와 해를 나눠 팔기(공제 두 번)를 제안.
- 의제취득가 계산 도구, 가이드 콘텐츠(과세 개요·시행 시기·절세법·거래소별 계산법). 해외금융계좌 신고(월말 5억 초과) 언급.

## CoinTracker (cointracker.com, 미국) — 2026-10-02 리뷰 기사 기준 (공식 사이트는 자동 조회 차단)
- 거래소·지갑·블록체인 500곳 이상 연결, 코인베이스 공식 세금 파트너(코인베이스 앱 안에서 1099-DA 대조).
- 실시간 포트폴리오 대시보드(전 계정 보유·평가손익), 실시간 손실 수확(tax-loss harvesting) 대시보드(Prime 이상).
- 취득가 방식 FIFO·LIFO·HIFO·ACB·개별 지정, 연중 변경. 미국 서식(8949, Schedule D), TurboTax 등 내보내기.
- **회계사 포털**: 고객의 거래 내역·세금 보고서·대사 자료에 접근 (Base 이상). 별도 Full Service(전문가가 대신 정리) 플랜.
- 요금: 무료 / Base $59(100건) / Prime $199(1,000건) / Ultra $599(10,000건) / Ultra+ $1,999 / Full Service(최대 30만 건). 거래 건수 구간제.
- 약점(리뷰): 화면이 낡고 어렵다, DeFi(LP 예치를 양도로 계산해 이익 중복, 브릿지 짝 실패로 가짜 손익)·L2·솔라나 DeFi는 손으로 고쳐야 한다,
  이체 짝이 안 맞으면 취득가 0원으로 전액 이익 처리, 중간에 가입하면 과거 매수 기록이 없어 취득가 0원, 거래량 적은 토큰 시세 부정확.
  "자산 10만 달러 이상이거나 DeFi가 많으면 결국 회계사 검토가 필요하다."

## 우리가 앞선 점
- 거래소 9곳(해외 7 + 국내 2) API, 개인 지갑(비트코인·EVM 5개 체인·트론·솔라나), 선물·Earn·P2P·카드 결제·마진·듀얼 인베스트먼트까지 수집.
- **거래소 ↔ 지갑 이체를 블록체인 거래 번호로 짝지어 취득가를 이어 감** (경쟁사는 지갑이 없어 거래소 간 이동 시 취득가가 끊김).
- **잔고 대조**로 빠진 거래를 찾아냄 (경쟁사에는 없음). 주소 오염 사기 거래 자동 제외.
- 키와 거래 내역을 서버에 두지 않음 (코택스는 서버 저장).
- 세무사 검토 선택지 (경쟁사 둘 다 신고 대리 없음).

2. ✅ **업비트 화면 복사·붙여넣기 가져오기** + 거래 번호 없는 이체 짝짓기(R11) (2026-10-02)
3. ✅ **직접 입력** — 원화 매수·매도, 교환, 입출금, 보상·에어드랍, 2026년 말 보유분 (2026-10-02)
4. ✅ **절세 도구** — 연말 정리 시뮬레이션, 남은 공제, 매도 플랜, 해 나눠 팔기 (2026-10-02)
5. **가입 없는 간이 계산기 + 가이드 콘텐츠** — 첫 화면에서 바로 체험, 검색 유입.
6. ✅ **해외금융계좌 신고 도우미** (경쟁사에 없음) — 해외 거래소 월말 잔고 합계, 5억원 초과 달 표시 (2026-10-02)
7. 요금제·약관·환불 정책 페이지, 구글·네이버 로그인.

## CoinTracker 대비 발전 방향 (2026-10-02)
**출시 전 기반 (로컬 저장 방식의 약점 보완)**
1. 암호화 백업·복원 (+ 선택형 종단간 암호화 클라우드 백업으로 여러 기기 사용) — 지금은 브라우저 데이터를 지우면 모두 사라짐.
2. 통합 점검 화면(할 일 목록): 검토 필요 분류·잔고 대조 차이·시세 없음·보유 부족·오래된 동기화를 한곳에 모아 "신고 준비도"로 보여 줌.
3. 시세 보강: 업비트·바이낸스에 없는 토큰을 CoinGecko·DEX 시세로 (지금은 0원 처리).
4. 동기화 알림: API 보관 기간이 짧은 거래소(OKX 3개월, MEXC 1개월)를 위해 월 1회 알림.

**핵심 차별화: 세무사 포털** (CoinTracker 회계사 포털 + Full Service에 해당)
5. 고객 초대 → 고객이 데이터를 사무소 공개키로 암호화해 제출 → 세무사 화면에서 여러 고객 관리(진행 상태, 검토 메모, 분류 수정 요청, 확정 보고서).

**범위 확장**
6. 범용 CSV 열 연결 화면 (지원하지 않는 거래소도 파일로), 브릿지 짝짓기(체인이 다른 R11), 체인 추가(BSC·아발란체 등), 기본 DeFi 해석(LP·대출·스테이킹 파생).

**사용성**
7. 포트폴리오 홈 대시보드(전 계정 보유·평가손익·추이), 모바일(PWA부터).

## 세무사 확인 요청
- 선입선출법 선택을 넣을지: 소득세법 시행령상 가상자산 취득가액 산정은 이동평균법으로 알고 있으나, 코택스는 선입선출·거래소별 혼합을 선택하게 함.
- 코인허브: "취득가액을 확인하기 어려우면 양도가액의 일정 비율(최대 50%)을 필요경비로 의제할 예정"이라고 안내. 사실이면 검토 항목 #9(보유 부족분 취득가)에 반영.
- 홈택스 신고 메뉴·서식: 2028년 5월 첫 신고 전이라 화면이 정해지지 않음. 코택스는 "종합소득세 신고 → 기타소득 분리과세"로 안내.
