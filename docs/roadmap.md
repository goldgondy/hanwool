5. 오류 신고·문의 경로 (이메일 또는 폼).

**세무사님이 할 것**

## 세무사님이 준비할 자료

**A. 정답지 사례 (가장 중요)** — 가상의 투자자 3~5명, 거래 10~30건씩, 세무사님이 손으로 계산한 결과(양도차익·과세표준·세액)까지.
코드가 맞는지 판단하는 기준이 되고, 체험용 예시 데이터로도 쓴다. 추천 인물:
1. 업비트만 쓰는 직장인 (원화 매수·매도, 2026년 말 보유분 의제취득가).
2. 업비트 → 바이낸스로 옮겨 USDT로 거래 (거래소 간 이체, 코인끼리 교환).
3. 개인 지갑 사용자 (거래소 → 메타마스크, 스테이킹 보상·에어드랍).
4. 손실이 난 해와 이익이 난 해 (손익통산, 250만원 공제).
5. 선물·Earn 사용자 (검토 필요 항목 확인용).

**B. 법령·서식**
- 2027년 시행 기준 소득세법·시행령 가상자산 조문 (개정 예정분 포함).
- 기획재정부·국세청 해석이나 안내 자료가 나오면 그때그때.
- 해외금융계좌 신고서 서식과 가상자산 관련 작성 요령.

**C. 사업 관련 결정·자료**
- 사업 형태: 세무사 사무소 부가 서비스 vs 별도 사업자 (결제·약관 명의가 달라짐).
- 세무사법상 광고·수임 관련 제한이 있는지 (온라인 서비스로 고객을 모으는 방식).
- 세무사 검토 수임료 범위, 셀프 도구 요금 의견.
- 평소 수임 시 고객에게 받는 자료 목록과 검토 체크리스트 (세무사 포털 설계용).

**D. 실제 파일 샘플 (금액·주소는 가려도 됨)**
- 빗썸 거래내역 엑셀·CSV (todo-later #4).
- 업비트 거래내역 화면 붙여넣기 결과, 바이낸스 CSV — 이미 지원하지만 실제 형식 확인용.
- API 키·비밀번호·복구 문구는 절대 채팅이나 파일로 주지 않는다. 앱 화면에만 입력.
