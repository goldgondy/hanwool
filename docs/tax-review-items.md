# 세무 검토 사항

세무사 판단이 필요한 항목을 한곳에 모은다. 결정되면 "결정"으로 옮기고, 앱의 해당 코드와 docs/classification.md를 함께 고친다.

마지막 갱신: 2026-09-30

## 검토 대기

| # | 항목 | 현재 앱 처리 | 세무사 의견 | 관련 코드 |
|---|---|---|---|---|
| 1 | **USDT 표시 가격의 원화 환산** (업비트에 없는 코인을 바이낸스 USDT 가격으로 평가할 때) | 업비트 KRW-USDT 시세(김치 프리미엄 포함). 업비트 USDT 시세가 없는 2024년 중반 이전은 ECB 환율 | 업비트 USDT 시세가 맞다고 봄 (잠정). **업비트 USDT 상장 전 기간을 어떻게 할지 미정** | `src/lib/server/price-history.ts` usdKrw |
| 2 | **달러(USD) 법정화폐 거래의 원화 환산** (코인베이스 등에서 실제 달러로 매수·매도) | ECB 환율 (임시) | 미정. 제안: 서울외국환중개 매매기준율 (한국은행 ECOS API) | `src/lib/server/price-history.ts` usdFiat |
| 3 | **거래 시점 시가** | 실제 주고받은 금액 우선(스테이블코인·법정화폐 거래, 거래소 체결), 없으면 거래 직전 1분 종가 | 주식처럼 실제 거래가액 (잠정) | `src/lib/tax/build-events.ts` |
| 4 | **의제취득가 시가** (2026-12-31) | 업비트 가격만 사용 | 대표 거래소들의 2026년 말 시가 (잠정). **거래소 범위와 계산법(평균·시각) 미정** | `src/lib/tax/build-events.ts` DEEMED_PRICE_TIME |

| 6 | **보상·이자·에어드랍 과세 시점** | 받을 때 과세 안 함, 취득가 0원 (팔 때 과세) | 팔 때 과세 (잠정) | `build-events.ts` reward/airdrop |
| 7 | **선물·파생상품 손익** (바이낸스·바이비트 무기한 선물의 실현 손익, 펀딩비, 선물 수수료) | 손익·펀딩비·선물 수수료 모두 미분류(검토 필요)로 두고 계산에서 제외. API 연결은 선물 지갑 잔고만 조회 | 미정. 선택지: ① 가상자산 양도소득에 포함 ② 해외파생상품 양도소득으로 분류과세 ③ 현행법상 과세 대상 아님 | `src/lib/importers/binance.ts`, `src/lib/ledger/bybit-build.ts` |
| 8 | **DeFi** (LP 예치·해지, 대출 담보, 리스테이킹) | 해석하지 않음 (미지원 DeFi) | 미정 | `src/lib/classify/classifier.ts` |
| 9 | **보유 부족분의 취득가** (입금 내역 누락 등으로 가진 것보다 많이 판 경우) | 부족분 취득가 0원 + 경고 | 미정 | `src/lib/tax/engine.ts` withdraw |
| 10 | **해외 CeFi 예치·대출 플랫폼 이자** (Nexo, YouHodler 등) | 아직 수집하지 않음. 수집하면 보상 정책(취득가 0원, 팔 때 과세) 적용 예정 | 미정 | (예정) |
| 11 | **파산·출금 정지 플랫폼에 묶인 자산의 손실** (하루인베스트, 델리오 등) | 처리 없음 | 미정. 손실 인정 여부, 인정 시점, 필요한 증빙 | (예정) |
| 12 | **잔고 대사에서 설명되지 않는 증가분** (예: stETH 리베이스, 기록되지 않은 보상) | 처리 없음 | 미정. 보상(취득가 0원)으로 볼지 | (예정) |
